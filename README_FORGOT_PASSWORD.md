# نظام Forgot Password - دليل شامل

## 📋 ملخص

تم تطبيق نظام **Forgot Password** الكامل مع ميزات:
- صفحة طلب إعادة تعيين كلمة المرور
- صفحة تغيير كلمة المرور الجديدة
- API endpoints آمنة
- معالجة شاملة للأخطاء
- توثيق كامل لإعدادات Supabase

## 🚀 البدء السريع (5 دقائق)

### 1. إعدادات Supabase
```
Authentication > URL Configuration
أضف:
- http://localhost:3000/auth/login
- http://localhost:3000/auth/reset-password
```

### 2. متغيرات البيئة
```env
NEXT_PUBLIC_APP_URL=http://localhost:3000
SUPABASE_SERVICE_ROLE_KEY=your_key
```

### 3. اختبار
```
/auth/login → Forgot password? → أدخل بريد → تحقق من البريل → غيّر الكلمة ✓
```

## 🔄 تدفق العملية

### المرحلة الأولى: طلب إعادة التعيين
```
صفحة الدخول
↓
انقر "Forgot password?"
↓
أدخل البريل الإلكتروني
↓
POST /api/auth/forgot-password
↓
Supabase يرسل بريل إعادة تعيين
```

### المرحلة الثانية: تغيير الكلمة
```
فتح البريل الإلكتروني
↓
انقر على الرابط في البريل
↓
/auth/reset-password?type=recovery&access_token=...
↓
أدخل كلمة المرور الجديدة
↓
POST /api/auth/reset-password
↓
رسالة النجاح ✓
```

## 🛡️ الميزات الأمنية

- ✅ التحقق من صيغة البريل الإلكتروني
- ✅ التحقق من طول كلمة المرور (8 أحرف على الأقل)
- ✅ التحقق من تطابق الكلمات
- ✅ استخدام `access_token` في Headers (آمن)
- ✅ صلاحية محدودة (ساعة واحدة)
- ✅ رسائل خطأ آمنة (لا تكشف البيانات)
- ✅ HTTPS في الإنتاج (موصى به)

## 🧪 اختبار التطبيق

### خطوات الاختبار:

1. **اذهب لصفحة الدخول**
   ```
   http://localhost:3000/auth/login
   ```

2. **انقر على "Forgot password?"**
   ```
   http://localhost:3000/auth/forgot-password
   ```

3. **أدخل بريد إلكتروني صحيح**
   ```
   يجب أن ترى: "Check your email"
   ```

4. **تحقق من البريل (قد يأخذ 30 ثانية)**
   ```
   ابحث عن بريل من Supabase
   قد يكون في Spam
   ```

5. **انقر على الرابط في البريل**
   ```
   يجب أن تنتقل إلى /auth/reset-password
   مع access_token في URL
   ```

6. **أدخل كلمة المرور الجديدة**
   ```
   يجب أن تكون 8 أحرف على الأقل
   ```

7. **أدخل التأكيد وانقر "Reset password"**
   ```
   يجب أن ترى رسالة النجاح
   ```

8. **اضغط "Go to sign in"**
   ```
   يجب أن تنتقل إلى صفحة الدخول
   ```

9. **حاول تسجيل الدخول بكلمة المرور الجديدة**
   ```
   يجب أن ينجح الدخول ✓
   ```

## ❓ استكشاف الأخطاء

### المشكلة: لم أستقبل بريداً

**الحل:**
- [ ] تحقق من مجلد Spam
- [ ] تأكد من `NEXT_PUBLIC_APP_URL` صحيح
- [ ] تأكد من Redirect URLs موجودة
- [ ] انتظر 30-60 ثانية

### المشكلة: الرابط في البريل لا يعمل

**الحل:**
- [ ] تأكد من أن Email Template يحتوي على `{{ .ConfirmationURL }}`
- [ ] جرب نسخ الرابط يدوياً من البريل
- [ ] تأكد من البريل قادم من `noreply@supabase.io`

### المشكلة: صفحة Reset تظهر خطأ "Invalid reset link"

**الحل:**
- [ ] تأكد من الرابط يبدأ بـ `?type=recovery&access_token=`
- [ ] جرب فتح الرابط مباشرة من البريل
- [ ] تحقق من انقضاء 60 دقيقة أم لا
